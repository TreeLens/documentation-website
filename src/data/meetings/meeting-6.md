---

## 2. 💬 Discussion and Decisions
- Given that one of the challenges encountered in our project so far is the lack of an annotated dataset suited to our needs, we can combine utility with convenience, following suggestions made by the course instructors during the MS2 presentation by using this gamification approach as a means to obtain our dataset.
- The objective, therefore, would be to develop, prior to the delivery of the MVP, an app that allows the average user to create backgrounds for our dataset. This includes an interface that allows for the uploading of tree images, followed by their cataloging. It should be noted that the verification of these cataloged entries marking them as either accepted or rejected will remain in place, as defined in the previous milestone, with the "Technician" actor responsible for this task. This process is intended to build a sufficiently large collection of cataloged tree images to serve as our dataset.
- Team suggestion: gamify the app similar to Pokémon GO.
- Vicente’s suggestion: gamify the app for tree enthusiasts, making it something like Duolingo.
- With these suggestions in mind, we conceived a system designed to encourage the average community member to actively participate in cataloging the trees in their city. This could be achieved through features such as streaks (like those in Duolingo), a scoring system based on the rarity of the cataloged tree (reminiscent of Pokémon), or ranked leagues (Emerald, Ruby similar to Duolingo). These are just some initial brainstorming ideas. 
- Marcos's suggestion is to create a mascot that dies if a streak is broken, similar to Duolingo or TikTok messages to encourage continued use.
- Discussion regarding a web app versus an APK; we decided to move forward with an APK.

---

## 3. 🌳 Beginning of Development
- Start by simply allowing the user to save a photo of a tree along with its corresponding classification.
- Once the system allows for the above, proceed to design a map that enables the user to view not only their own trees but also all the trees already cataloged in their vicinity.
- Add gamification only after the pipeline is complete.
- There is a possibility of adding a friendship system, quests, and in-system rewards. Nothing is set in stone; these ideas will only be considered once the aforementioned features are fully functional that is, once the collection of images for our dataset is already underway.
